# Wealth — 개인·가족 자산 통합 관리

Wealth는 주식, 은행, 연금·보험, 부동산, 세금, 투자 기록, 실현손익, 배당·이자 및 가계부를 **한 화면에서 조회하고 기록**하는 개인·가족용 셀프 호스팅 웹 앱입니다. 모바일과 데스크톱을 지원하며, 사용자의 금융 정보는 운영 서버에 저장됩니다.

> **시작하기:** 운영자가 발급한 계정으로 로그인 → 조회 범위(모두·가족 구성원) 선택 → **종합 자산**에서 계좌와 자산을 등록 → 필요 시 **설정**에서 증권사/데이터 소스 연결 → **주식 투자**와 **머니 로그**에서 기록과 현금흐름 확인.
>
> **현재 운영 기준:** v2.1.3 (2026-10-22). [변경 내역](CHANGELOG.md) · [운영 및 기술 상태](docs/PROJECT_STATE.md) · [개발 계획](docs/ROADMAP.md) · [이전 README 운영 기록](docs/README_OPERATIONS_ARCHIVE.md)

## 1. 로그인 및 기본 화면 사용법

운영자가 안내한 Wealth 주소에서 로그인합니다. 초기 비밀번호 변경 안내가 나타나면 안내에 따라 새 비밀번호로 변경합니다. 본인이 사용하는 브라우저 이외의 기기에서는 로그인 상태 및 로그아웃 여부를 확인하세요.

화면 상단의 **조회 범위**에서 `모두`, `아빠`, `엄마`, `자녀` 등 구성원을 선택하면 지원하는 자산·기록·차트가 선택한 범위로 바뀝니다. 구성원 버튼은 실제 등록 상태에 따라 다를 수 있습니다. 수치가 바뀌지 않으면 연결된 계좌의 소유자와 선택 범위를 확인하세요.

하단 메뉴는 **홈 / 주식 투자 / 종합 자산 / 머니 로그 / 설정**으로 이동합니다. 모바일에서 주식 투자·머니 로그의 하위 탭은 좌우 스와이프하여 숨겨진 메뉴를 열 수 있습니다. 화면을 확대하는 동작이 아니라 **탭 메뉴 자체를 가로로 스크롤**하는 기능입니다.

상단 **시세 갱신**은 시장 가격을 새로고침하는 동작이며 **계좌 동기화**는 연결된 증권사 정보를 갱신하는 별도 동작입니다. 연결되지 않은 계좌는 자동으로 갱신되지 않을 수 있습니다.

## 2. 홈 — 전체 자산과 순자산 추이

홈에서 전체 순자산, 자산 구성을 확인하고 **순자산 추이**로 이동할 수 있습니다.

**순자산 추이**는 사용자가 날짜별로 확인·저장한 순자산 기록입니다. 기간 탭 `일간 / 주간 / 월간 / 연간 / 전체`를 선택하여 조회 범위를 바꿉니다. 선 그래프와 증감 막대는 서로 다른 의미의 값이므로 축·표시 단위를 확인하세요. **최신 순자산 및 기준일**은 최신 저장 기록을 나타냅니다. 차트 아래에서는 과거 기록 조회 및 필요한 기록의 추가·수정·삭제를 할 수 있습니다.

**유의:** 날짜별 순자산 기록은 실제 증권사 수익률과 같지 않습니다. 입출금·자산 신규 등록·부채 변경 등에 따라 순자산이 달라질 수 있습니다. `조회 범위`와 기록 기준일을 확인한 뒤 비교하세요.

## 3. 종합 자산 — 금융 계좌와 자산 등록

종합 자산에서 자산 유형을 선택합니다.

| 메뉴 | 할 수 있는 일 |
|---|---|
| 📈 증권 | 증권계좌 조회·추가, 주식 평가액·예수금 확인, 계좌 동기화와 잔고 파일 가져오기 |
| 🏦 은행 | 예금·입출금·적금 등 은행 자산 관리 |
| 🛡️ 연금·보험 | 연금과 보험 관련 자산 및 설정 조회·기록 |
| 🏠 부동산 | 부동산 자산 등록·평가와 보유 내역 확인 |
| 🧾 세금 | 지원하는 금융·자산 관련 세금 정보 조회 |

**증권계좌 등록:** `증권계좌 추가`에서 소유자·증권사·계좌 정보를 입력하고 저장합니다. 계좌 수가 늘어나면 탭의 괄호 숫자도 바뀝니다. `증권계좌 가져오기`는 지원하는 양식의 파일로 계좌를 일괄 등록할 때 사용합니다. 잔고 가져오기에는 별도 양식이 있을 수 있으므로 화면의 **샘플 파일**을 먼저 확인하세요.

**연결형 계좌:** 지원하는 증권사 API 또는 Toss WTS 등의 연결이 설정되어 있을 때만 동기화가 가능합니다. 계좌 추가와 연결 설정은 서로 다른 작업입니다. 저장된 실제 금융 데이터는 삭제·수정 전에 반드시 대상 계좌와 소유자를 다시 확인하세요.

## 4. 주식 투자 — 포트폴리오부터 절세계좌까지

모바일 하위 메뉴는 가로로 이동하여 선택합니다.

| 메뉴 | 주요 기능 |
|---|---|
| 📊 포트폴리오 | 보유 주식 구성, 평가 및 수익 현황 확인 |
| 🗺️ 히트맵 | 종목별 비중·등락을 시각적으로 비교 |
| 🗓️ 주식기록 | 날짜별 투자 자산을 기록하고 기간별 변화를 조회 |
| 🎯 전략 버킷 | 투자 전략별 자산을 구분·분석 |
| 🧾 절세계좌 | ISA·연금 등 절세 관련 계좌 정보 확인 |
| 📋 보유종목 | 보유 종목별 수량·가격·평가액 확인 |

**주식기록 추가:** 기록 화면의 `추가`를 눌러 해당 날짜의 자산 정보를 저장하거나 기존 기록을 수정할 수 있습니다. 차트 조회 시 기간과 소유자 범위를 먼저 확인하세요.

## 5. 머니 로그 — 캘린더, 손익, 배당, 가계부, 공모주

모바일 하위 메뉴에서 좌우로 이동하여 원하는 화면을 선택합니다.

| 메뉴 | 주요 기능 |
|---|---|
| 📅 캘린더 | 날짜별 금융 일정·수입·지출과 기록 확인 |
| 📈 실현손익 | 매도 등으로 실현한 손익 기록과 기간별 추이 |
| 💰 배당·이자 | 실제 배당·이자 수입, 기간·증권사별 조회 |
| 🧾 가계부 | 수입·지출 기록, 기간별 현금흐름과 거래 내역 |
| 🔔 공모주 | IPO 일정, 주관 증권사 필터, 청약·배정·상장 기록 |

**실현손익과 배당·이자**는 주식 평가손익과 다릅니다. 해당 메뉴의 기간·소유자·증권사 조건을 확인해야 비교가 정확합니다. 가계부는 월간 현금흐름과 개별 거래 내역을 함께 확인할 수 있습니다.

### 공모주 사용법

`전체 / 예정 / 진행 / 과거` 탭으로 상태를 선택하고, 월 선택기와 **주관 증권사** 필터로 목록을 좁힙니다. 기업별 `자세히`에서 청약 기간, 상장 예정·실제일, 진행 상태 및 출처를 확인합니다. `새로고침`, `과거자료 가져오기`는 서로 다른 동작입니다. `일정 제외`는 목록에서 숨기는 설정이며 기존 신청·배정 원본 기록을 삭제하는 기능이 아닙니다.

**일정 정렬(현행 v2.1.3 기준):** 목록은 `청약 시작일` 우선, 값이 없으면 `상장 예정일`, 마지막으로 `실제 상장일`을 사용한 표시 날짜 순서입니다. `전체·예정·진행`은 오름차순, `과거`는 내림차순입니다. **모든 항목이 실제 상장일순으로 정렬되는 것은 아닙니다.** 실제 청약 가능 여부와 정확한 일정은 반드시 해당 증권사와 공식 공시에서 확인하세요.

## 6. 설정 — 계좌/API/데이터 소스 연결

설정 페이지의 인증 정보 입력은 외부 서비스를 사용하기 위한 별도 기능입니다. **아이디·비밀번호·API 키를 저장소 코드나 공개 이슈에 붙여넣지 마세요.** 저장된 비밀정보는 화면에서 다시 전체 표시되지 않을 수 있으며, 비밀번호 입력칸이 비어 있다고 기존 값이 삭제됐다는 뜻은 아닙니다.

### 🏛️ KRX Data Marketplace

- **용도:** 과거 공모주 전체 조회를 위한 KRX 로그인 연동입니다. 일반 주식 시세 갱신과 별개입니다.
- **설정:** KRX에서 발급받은 아이디·비밀번호를 입력하고 `저장`합니다.
- **연결 확인:** `연결 확인` 버튼으로 설정 유효성을 확인합니다. 로그인 가능 여부와 실제 데이터 제공 범위는 다를 수 있습니다.
- **삭제:** `삭제`를 누르면 저장된 KRX 인증 정보를 해제합니다. 기존 IPO 수집 데이터 삭제와 동일하지 않습니다.
- **보안:** 사용자별 서버 비밀정보에 저장하며, 저장된 비밀번호를 다시 표시하지 않습니다.

### 📊 시장 데이터 API · OpenDART

공모주 증권신고서·관련 공시 분석에 쓰이는 API 키를 등록합니다. OpenDART에서 발급받은 **API Key**를 입력한 뒤 `연결 확인` 및 `저장/교체`를 사용합니다. 이는 KRX 로그인과 별개입니다.

### 증권사 OpenAPI와 Toss WTS

지원되는 증권사는 증권사별 App Key·Secret 등 필요한 인증 정보를 등록하고 상태를 확인할 수 있습니다. Toss WTS는 별도 실행·세션 및 인증 환경이 필요할 수 있습니다. 지원되지 않거나 설정되지 않은 연동은 Wealth가 임의로 연결하지 않습니다.

## 7. 데이터 보호와 문제 해결

- 자산을 찾을 수 없을 때: 조회 범위 → 계좌 소유자 → 연동 상태 → 마지막 동기화 결과 순으로 확인합니다.
- 공모주 일정이 다를 때: 청약일/상장일 구분, 날짜별 출처, 조회 월, 제외 목록, 증권사 필터를 확인합니다.
- 모바일에서 메뉴가 보이지 않을 때: 하위 메뉴를 좌우로 스크롤합니다.
- 차트 값이 예상과 다를 때: 기간, 표시 단위, 기록 기준일, 예수금·입출금 반영 여부를 확인합니다.
- API 연결이 실패할 때: 입력값, 발급 사이트의 인증상태, 권한 및 서버 로그를 확인하고 **인증 정보를 공개하지 않습니다**.

이 앱은 금융기관의 원장이나 세금 확정 신고를 대체하지 않습니다. 공모주 일정·수익률·세액·시세는 공식 자료와 대조하여 사용하세요.
