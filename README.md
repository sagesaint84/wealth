### 배포 계약 — 이번 문서 작업에서 변경하지 않음

`app/updater/releases.py`의 ReleaseVerifier는 **최신 main HEAD에 대응하는 성공한 GHCR 빌드**를 요구한다. `.github/workflows/docker-publish.yml`은 main Push마다 실행된다. 문서 PR도 main에 병합하면 새 SHA와 GHCR 빌드가 생길 수 있으므로 **사용자 승인 전 이 문서 PR을 Ready/병합하지 않는다.** 이 작업은 feature 브랜치 Push와 Draft PR 제출만 허용하며 main Push·APP_VERSION 변경·버전 태그 이동·GHCR 발행·Oracle Docker/worker/state 변경을 하지 않는다.

문서 전용 변경을 발행하지 않는 정책은 **Issue #182의 별도 설계 대상**이다. 단순 paths-ignore 추가는 최신 main용 빌드가 없어 업데이트 확인을 막을 수 있으므로, ReleaseVerifier·배포/검증 계약을 함께 검토하고 별도 승인하기 전에는 적용하지 않는다.

**아래의 개발 후보·NOT_RUN·HOLD·Draft·미배포 문구는 각 절 작성 당시의 역사적 기록이다. 현재 운영 상태는 이 상단 절을 우선하며, 기술 계약·사용자 설명과 과거 버전 이력은 삭제하지 않는다.**

## 1. 처음 시작하는 순서

Wealth를 처음 사용하는 경우 아래 순서대로 진행하면 됩니다.

1. **로그인하기:** 운영자가 알려준 Wealth 주소를 열고 발급받은 계정으로 로그인합니다. 첫 로그인에서 비밀번호 변경 안내가 뜨면 먼저 변경합니다.
2. **조회 범위 확인:** 화면 상단의 **조회 범위**에서 **모두** 또는 특정 가족 구성원을 선택합니다. 구성원 선택에 따라 자산·거래·차트의 대상이 달라집니다.
3. **종합 자산 등록:** **종합 자산**에서 증권·은행·연금/보험·부동산 등의 기존 자산과 계좌를 입력합니다. 등록하지 않은 데이터는 자동으로 만들어지지 않습니다.
4. **필요한 연결만 설정:** 자동 조회가 필요하다면 **설정**에서 지원되는 증권사 계정·OpenAPI·OpenDART 등의 연결을 등록합니다. 외부 연결 없이 수동 기록을 사용하는 기능도 있습니다.
5. **결과 확인:** **홈**에서 자산의 전체 모습, **주식 투자**에서 보유종목, **머니 로그**에서 손익·배당·이자·가계부·공모주를 확인합니다.
6. **기록과 동기화 구별:** 직접 입력한 기록과 외부에서 가져온 값의 날짜·소유자·출처를 확인합니다.

**첫 사용 팁:** 처음부터 모든 API를 연결할 필요는 없습니다. 계좌와 소유자를 정확히 등록한 뒤, 필요한 연결을 하나씩 추가하는 편이 결과를 검증하기 쉽습니다.

## 2. 화면 이동과 공통 조작

데스크톱에서는 주 메뉴가 왼쪽에, 모바일에서는 화면 아래쪽에 표시됩니다.

| 주 메뉴 | 무엇을 하나요? |
|---|---|
| **홈** | 자산 포트폴리오, 순자산 추이, 주요지수 확인 |
| **주식 투자** | 보유 주식·포트폴리오·히트맵·투자 기록·절세계좌·종목 신호 확인 |
| **종합 자산** | 증권·은행·연금/보험·부동산·세금 관련 데이터 관리 |
| **머니 로그** | 캘린더·실현손익·배당/이자·가계부·공모주 이용 |
| **설정** | 데이터 소스·계정·알림·자동화·사용자 환경 설정 |

### 조회 범위는 무엇인가요?

화면 위쪽 **조회 범위**에서 **모두**를 선택하면 허용된 가족 범위의 데이터를 통합해서 볼 수 있습니다. **아빠·엄마·자녀** 같은 개별 항목은 실제 등록된 구성원에 따라 다르게 표시됩니다.

- 계좌나 기록을 새로 만들 때 **소유자**를 잘못 지정하지 않았는지 확인하세요.
- 특정 가족을 선택하면 일부 차트·계좌·금액이 제외될 수 있습니다.
- 다른 사용자의 개인 데이터와 한 사용자의 가족별 조회 범위는 서로 다른 개념입니다.

### 시세 갱신과 계좌 동기화의 차이

- **시세 갱신:** 보유 자산 평가에 필요한 시장 가격을 다시 조회합니다.
- **계좌 동기화:** 연결·설정된 증권사에서 지원되는 잔고와 보유종목 등을 읽어 옵니다.
- **수동 기록 저장:** 사용자가 입력한 계좌·거래·자산 기록을 남깁니다.

시세 갱신이 계좌 동기화를 의미하지 않으며, 지원하지 않는 외부 계좌까지 자동으로 조회하지 않습니다. 마지막 갱신 시점과 결과를 함께 확인하세요.

### 모바일에서 탭이 안 보이나요?

**주식 투자·종합 자산·머니 로그**의 하위 메뉴는 모바일에서 가로로 스크롤할 수 있습니다. 메뉴 줄을 좌우로 밀어 나머지 탭을 찾으세요. 페이지 전체가 옆으로 이동하는 것과는 다릅니다.

## 3. 홈 — 내 자산을 한눈에

홈 상단의 **자산 포트폴리오 / 순자산 추이 / 주요지수** 탭을 눌러 기존 세 영역을 전환합니다. 첫 진입은 자산 포트폴리오입니다. 탭에 초점을 두고 좌우 방향키 또는 Home/End로도 이동할 수 있습니다.

### 자산 포트폴리오

총자산·부채·순자산 등 주요 금액과 자산별 구성을 확인합니다. 화면의 **자산 상세보기**를 통해 종합 자산에서 세부 내역을 살펴볼 수 있습니다. 총자산과 순자산은 서로 다르며, 일반적으로 순자산은 자산에서 부채를 고려한 값입니다.

### 순자산 추이

날짜별로 저장된 순자산 기록을 그래프로 확인합니다. 기간 선택, 추이 그래프, 기록 조회·추가·수정·삭제 기능을 사용합니다. 표시된 **최신 순자산과 기준일**은 마지막으로 저장된 기록을 기준으로 하므로, 당일 시세를 무조건 뜻하지는 않습니다.

차트의 자산 값 선과 변화량 막대는 의미와 축이 다를 수 있습니다. 조회 기간과 단위를 보고 비교하세요. 입출금, 새 자산 등록, 부채 변경으로도 순자산이 변하므로 차트의 변화를 투자 수익률로 단정하지 마세요.

### 주요지수

국내외 시장 지수와 제공되는 금리·시장 지표를 확인합니다. 출처·기준 시점·조회 실패 상태를 확인하세요. 일부 시장 데이터는 실시간 체결가가 아닐 수 있습니다.

**홈 3탭 출시 대상:** 기존 섹션·데이터·렌더러를 사용합니다. 순자산 추이는 `#home/history`, 주요지수는 `#home/markets` 주소로 직접 열 수 있습니다. 공포탐욕지수 수치 연동은 별도 후속 개발입니다. [개발 요청 #176](https://github.com/sagesaint84/wealth/issues/176) · [릴리스 상태·성능 예외 기록](docs/PR177_RELEASE.md)

## 4. 종합 자산 — 계좌와 자산 등록하기

상단에서 원하는 자산 유형을 선택합니다.

| 구분 | 주요 사용법 |
|---|---|
| **증권** | 증권계좌 등록, 보유종목·예수금·평가액 확인, 지원되는 잔고 가져오기 및 동기화 |
| **은행** | 입출금·예금·적금 등 은행 자산 기록과 잔액 관리 |
| **연금·보험** | 연금·보험 관련 금액과 가입 정보, 지원되는 국민연금 상세 분석 |
| **부동산** | 보유 부동산의 평가 금액과 관련 자산 기록 |
| **세금** | 금융소득 및 지원되는 세금·절세 분석, 가정 기반 예상 계산 |

### 증권계좌 처음 등록하기

1. **종합 자산 → 증권**으로 이동합니다.
2. 계좌 추가 기능을 열고 **소유자, 증권사, 계좌 유형·식별 정보** 등 요구 항목을 입력합니다.
3. 저장한 뒤 목록에서 소유자와 계좌가 올바른지 확인합니다.
4. 지원되는 외부 연결이 있다면 **설정**에서 별도 인증을 구성하고, 이후 계좌 동기화 기능을 사용합니다.
5. 보유종목·예수금·평가금액이 실제 자료와 일치하는지 검토합니다.

**계좌 등록과 계좌 연동은 다릅니다.** 계좌를 목록에 추가했다고 증권사의 최신 잔고가 자동으로 들어오는 것은 아닙니다.

### 파일·PDF에서 자산 가져오기

Wealth는 지원 양식의 증권계좌·매도 실현손익·배당 데이터 파일 및 AccountInfo 계좌통합현황 PDF 가져오기 기능을 제공합니다. 화면의 **미리보기·선택·확인** 절차를 거쳐 반영하세요.

저장소에서 제공하는 예시 파일: [증권계좌](샘플_증권계좌.xlsx) · [배당](샘플_배당.xlsx) · [매도 실현손익](샘플_매도실현손익.xlsx) · [타 증권사 보유종목](샘플_타증권사_보유종목.xlsx)

- 가져오기 전 **소유자, 계좌번호 마스킹, 종목, 금액, 날짜**를 대조합니다.
- 동일 거래를 수동·파일·동기화 경로에서 두 번 반영하지 않도록 주의합니다.
- AccountInfo PDF는 브라우저 미리보기에서 선택해 반영하며, 모든 문서 형식이 동일하게 지원되는 것은 아닙니다.

### 국민연금·세금 분석의 해석

국민연금 분석은 등록한 납부 이력·가입 정보와 사용자가 설정한 가정을 사용합니다. 수령 시나리오·세금 효과·현금흐름은 **시뮬레이션**이며 미래 연금액이나 최종 세액의 보증이 아닙니다. 입력되지 않았거나 근거가 부족한 값은 결과에서 별도로 구분해야 합니다.

## 5. 주식 투자 — 보유종목과 투자 기록

| 하위 메뉴 | 사용 목적 |
|---|---|
| **포트폴리오** | 보유 투자자산의 구성과 평가·성과 파악 |
| **히트맵** | 종목별 비중과 등락을 색으로 비교 |
| **주식기록** | 날짜별 주식 자산 기록, 기간별 자산·손익 흐름 확인 |
| **전략 버킷** | 투자 목적이나 전략별 종목·자산 구분 |
| **절세계좌** | ISA, 연금저축, IRP 등 등록된 절세 계좌 관련 현황 |
| **보유종목** | 종목·계좌별 수량, 평가 정보 및 제공되는 기술적 신호 조회 |

### 주식기록과 평가손익

주식기록은 **특정 날짜의 기록**을 관리합니다. 조회 기간을 변경하면 그래프에 보이는 시점·값의 범위가 달라집니다. 매도해서 확정된 금액은 **머니 로그 → 실현손익**과 구별해 보세요.

### 보유종목 기술적 신호

지원되는 종목에서는 **20일·50일 이동평균선 이탈**, **골든크로스·데드크로스** 등 신호를 확인할 수 있습니다. 종목과 시장 데이터가 충분할 때만 판단 가능하며, 신호는 매수·매도 주문이 아닙니다. 데이터 미제공·조회 실패는 신호 없음과 구분해야 합니다.

## 6. 머니 로그 — 날짜별 돈의 흐름

### 캘린더

금융 일정과 기록을 날짜 기준으로 모아 확인합니다. 같은 날짜에 여러 유형의 항목이 표시될 수 있으므로 해당 항목의 종류·출처를 확인합니다.

### 실현손익

매도 등으로 **실현된 손익**을 기간·계좌·소유자 기준으로 조회합니다. 현재 보유 중인 종목의 평가손익과 섞어서 해석하지 마세요. 가져온 기록의 중복과 실제 체결 일자를 확인하세요.

### 배당·이자

현금으로 발생한 **배당금·이자**와 제공되는 예상·분석 결과를 확인합니다.

1. **배당·이자**로 이동합니다.
2. **조회 기간·소유자·증권사** 조건을 선택합니다.
3. 실제 수령 기록과 예상 값이 있다면 서로 구분합니다.
4. 그래프와 상세 내역의 기준 날짜·금액·통화를 확인합니다.
5. 새로운 기록을 넣을 때 같은 지급 건이 파일 가져오기와 중복되지 않도록 검토합니다.

금융소득 합계·세금 예측 화면의 값은 확정 신고액이 아닙니다. 특히 배당의 세금 처리 방식과 종합과세 판단은 등록 자료·가정·법령 기준을 확인해야 합니다.

### 가계부

수입·지출을 기록하고 월간 현금흐름과 거래 내역을 확인합니다. 기간과 가족 조회 범위에 따라 합계가 달라질 수 있습니다. 지원되는 OCR·가져오기 기능을 이용할 경우 자동 인식 결과는 저장 전에 검토하세요.

### 공모주

1. **공모주** 메뉴에서 **전체 / 예정 / 진행 / 과거** 등 상태를 선택합니다.
2. 조회 월과 **주관 증권사** 필터를 사용합니다.
3. 기업별 상세정보에서 **청약 기간·상장 예정일·실제 상장일·출처**를 확인합니다.
4. 청약·배정·상장 등의 사용자 기록은 실제 증권사 내역과 맞춰 관리합니다.
5. 잘못되거나 원하지 않는 일정을 제외할 때는 **일정 제외·복원** 기능의 의미를 확인합니다.

**공모주 목록 정렬 기준:** 청약 시작일을 우선 사용하고, 없으면 상장 예정일, 그다음 실제 상장일을 사용합니다. 예정·진행 등은 이 표시 날짜 기준 오름차순, 과거 목록은 내림차순입니다. **모든 항목이 실제 상장일순은 아닙니다.**

실제 청약 가능 여부와 청약·배정 세부 조건은 해당 증권사의 안내와 공식 공시를 최종 확인하세요. **과거자료 가져오기**와 일반 **새로고침**은 서로 다른 작업이며, 자동 조회 실패가 과거 기록을 삭제한다는 뜻은 아닙니다.

## 7. 설정 — 처음 필요한 것부터 연결하기

외부 연동은 선택 사항입니다. 일부 설정은 **계정 관리자 또는 운영자 권한**이 있어야 변경할 수 있습니다.

### 사용자·가족·화면 설정

- **계정:** 상단의 비밀번호 변경·로그아웃 기능을 이용합니다. 처음 받은 임시 비밀번호는 변경하세요.
- **사용자 관리:** 관리자는 사용자 계정을 만들고 접근 상태를 관리할 수 있습니다. 일반 사용자에게 관리자 메뉴가 보이지 않을 수 있습니다.
- **가족·소유자:** 자산이나 기록을 등록할 때 올바른 소유자와 조회 범위를 선택합니다.
- **화면 환경:** 제공되는 테마·색상·표시 환경 설정은 자신의 취향에 맞게 선택합니다.
- **알림·자동화:** 설정에 보이는 지원 채널·자동화 기능만 활성화하고, 연결 상태를 확인합니다.

### 증권사 OpenAPI 연결

Wealth에는 토스증권, KB증권, NH투자증권, 한국투자증권(KIS), 키움증권 등 지원 범위가 서로 다른 연동이 있습니다.

1. 연결할 증권사에서 **공식적으로 발급받은 인증정보**를 준비합니다.
2. Wealth **설정**의 해당 증권사 항목에서 화면이 요구하는 키·계좌 정보를 입력합니다.
3. 저장 후 제공되는 **연결 확인·상태 확인** 기능으로 정상 여부를 확인합니다.
4. 연결이 가능한 경우 등록된 계좌와 연결한 뒤 **계좌 동기화**를 시도합니다.
5. 가져온 보유종목·수량·예수금·실현손익을 증권사 원본과 대조합니다.

**주의:** 증권사마다 지원되는 잔고·거래·실현손익 API가 다릅니다. 한 증권사에서 가능한 기능이 모든 증권사에서 제공되지는 않습니다. 키가 저장됐다고 자동 주문·매매가 실행되는 것은 아닙니다.

### OpenDART 설정

**용도:** 기업 공시·공모주 관련 정보를 확인하는 데이터 소스입니다.

1. 공식 [OpenDART](https://opendart.fss.or.kr/)에서 자신의 API 키를 준비합니다.
2. Wealth **설정 → OpenDART** 항목에 키를 입력하고 저장합니다.
3. **연결 확인** 결과를 확인합니다.
4. 실제 공시가 조회되는지 해당 공모주 상세정보에서 확인합니다.

OpenDART 키는 증권사 계좌 연동 키와 다릅니다. 값이 비어 있거나 연결되지 않으면 일부 외부 공시 정보가 제공되지 않을 수 있습니다.

### KRX Data Marketplace 설정

**용도:** 공모주 **과거자료 조회** 등에 필요한 별도 KRX 연결입니다.

1. [KRX Data Marketplace](https://data.krx.co.kr/)에서 사용할 계정을 준비합니다.
2. Wealth 설정의 **KRX Data Marketplace** 영역에 로그인 정보를 입력하고 **저장**합니다.
3. **연결 확인**을 눌러 인증 상태를 확인합니다.
4. 공모주 메뉴의 과거자료 미리보기·가져오기 흐름에서 필요 자료를 검토합니다.
5. 더 이상 사용하지 않으면 설정 화면의 **삭제** 기능으로 연결 정보를 제거합니다.

KRX 인증정보 삭제와 이미 저장한 공모주 기록 삭제는 다른 작업입니다. 저장된 비밀번호는 보안상 다시 표시되지 않습니다.

### Toss WTS 연결

Toss WTS는 선택적인 **읽기 전용 피드**이며, 일반적인 증권계좌 등록과 다릅니다. 운영자가 Toss WTS 실행 환경을 준비한 경우 지원되는 설정·QR 인증·세션 상태 확인 절차를 사용합니다. 필요한 실행 파일이나 인증 환경이 없다면 기능이 동작하지 않을 수 있습니다.

QR 인증·세션은 사용자별로 분리하여 관리합니다. 세션 파일이나 확인 문자를 공개 채팅·이슈·저장소에 게시하지 마세요. 자세한 관리자 설정·운영 조건은 [Toss WTS 인증 운영 문서](ops/toss-auth/README.md)를 참고하세요.

### 알림·자동화 연결

지원되는 텔레그램·디스코드·카카오 연동과 자동화 항목은 설정 화면에서 제공되는 범위 내에서 구성합니다. 서비스별로 **토큰, Webhook, OAuth 승인** 등 요구사항이 다릅니다. 저장 후 알림 테스트 또는 연결 상태 확인이 제공된다면 확인하고, 실제로 수신되는지 검증하세요. 연결 정보는 절대로 README·GitHub 이슈·스크린샷에 포함하지 마세요.

### 시스템 업데이트 (v2.1.5 후보)

**admin**은 관리자 콘솔의 **시스템 업데이트**에서, 권한을 받은 일반 계정은 **설정 > 시스템 업데이트**에서 접근합니다. 관리자는 사용자 관리 목록에서 선택한 계정에만 **시스템 업데이트 권한**을 부여·회수합니다. 변경마다 관리자 본인 비밀번호와 확인이 필요하고 일반 사용자의 role=user 및 사용자 관리 권한은 바뀌지 않습니다.

권한에는 상태·최신 배포본 확인, 설치, 정상 확인과 과거 Wealth 이미지 정리가 포함됩니다. 설치·정상 확인·정리 때는 호출자 **본인 비밀번호**를 입력합니다. 정리는 미리보기와 별도 승인 후에만 실행하며 현재·마지막 정상 롤백 이미지와 다른 서비스 이미지는 보존합니다. 권한이 회수되면 새 요청은 차단되고 이미 시작된 호스트 작업은 안전하게 계속됩니다.

v2.1.4 로그인 상태로 접근하면 **다시 로그인**이 필요할 수 있습니다. 기존 호스트 실행기를 재설치하지 않습니다. 이번 hotfix는 승인 후 사용자가 앱만 수동 배포하고, 첫 실제 원클릭 업그레이드는 v2.1.6에서 검증할 예정입니다. [권한·보안·운영 절차](docs/UPDATER_PERMISSIONS_V215.md).


## 8. 데이터의 의미와 유의할 점

| 표시되는 값 | 혼동하기 쉬운 값 |
|---|---|
| **순자산** | 총자산 또는 주식만의 평가금액 |
| **평가손익** | 매도 후 확정된 실현손익 |
| **실현손익** | 배당·이자 현금수입 |
| **배당 실제 수령액** | 지급 예정·세후 추정·목표 금액 |
| **순자산 기록의 기준일** | 지금의 실시간 시세 |
| **공모주 청약 시작일** | 상장 예정일 또는 실제 상장일 |
| **기술적 신호** | 자동 주문 또는 투자 권고 |

- 투자·연금·세금 추정치는 가정과 원천 데이터에 따라 달라집니다.
- 금융기관 원장·공식 공시·확정 세금 신고를 Wealth가 대체하지는 않습니다.
- **국내·미국 공포탐욕지수의 점수 자동 표시 기능은 아직 미구현**입니다. 현재 제공되는 외부 링크와 실제 점수 연동을 구별하세요.

## 9. 개인정보 보호 및 백업

- 계좌번호·비밀번호·API Key·Secret·토큰·세션 파일·실제 금융 JSON을 GitHub 또는 공개 로그에 게시하지 마세요.
- 계좌 소유자를 변경하거나 파일 가져오기·삭제를 실행하기 전에 대상과 미리보기를 확인하세요.
- 외부 조회 실패나 일시적으로 빈 결과가 생겼다고 과거 계좌 기록을 임의로 삭제하지 마세요.
- 서버에 저장된 사용자 자료와 웹 내보내기 기능의 포함 범위는 다를 수 있습니다. **웹 데이터 백업에는 비밀번호·API 비밀값·토큰·세션 키가 포함되지 않습니다.**
- 운영자가 시스템을 이동·복구할 경우 영구 데이터와 암호화·인증 설정의 보존 여부를 별도 점검해야 합니다.

## 10. 자주 묻는 질문

**Q. 처음 로그인했는데 금액이 모두 비어 있습니다.**  
A. 아직 계좌·자산·기록이 없거나 조회 범위가 다른 소유자로 선택됐을 수 있습니다. **종합 자산 → 계좌/자산 등록**, 조회 범위와 연결 상태부터 확인하세요.

**Q. 시세 갱신을 눌렀는데 보유종목 수량이 바뀌지 않습니다.**  
A. 시세 갱신과 계좌 동기화는 다릅니다. 증권사 연결 여부와 동기화 지원 범위를 확인하세요.

**Q. 가족 구성원을 바꿨더니 금액이 달라집니다.**  
A. 선택한 소유자 범위가 바뀌었기 때문일 수 있습니다. 기록과 계좌의 소유자 정보를 확인하세요.

**Q. 가계부·배당·실현손익의 합계가 서로 다릅니다.**  
A. 각 화면이 계산하는 금액의 의미가 다르며, 조회 기간·수령일·거래일·가져오기 여부가 다를 수 있습니다.

**Q. 공모주 목록의 순서가 상장일과 다릅니다.**  
A. 현행 정렬은 **청약 시작일 우선**입니다. 카드에서 청약일·상장 예정일·실제 상장일을 구분해 확인하세요.

**Q. 설정에 API 키가 보이지 않습니다. 삭제된 건가요?**  
A. 저장된 비밀값은 보안상 마스킹되거나 재표시되지 않을 수 있습니다. 연결 상태를 확인하고, 변경이나 삭제가 필요할 때 화면의 명시적 기능을 사용하세요.

**Q. 휴대전화에서 메뉴 일부가 보이지 않습니다.**  
A. 메뉴 탭 줄을 좌우로 스크롤해 보세요. 화면을 새로고침해도 문제가 지속된다면 사용 중인 브라우저와 화면 너비를 확인하세요.

**Q. 홈에서 포트폴리오·순자산 추이·주요지수가 탭으로 나뉘어 있지 않습니다.**  
A. 운영자가 홈 3탭 변경을 배포했는지 확인하세요. 적용 전 서버에서는 기존 세로 배치가 보일 수 있습니다. 적용 후에는 **자산 포트폴리오 / 순자산 추이 / 주요지수**로 전환합니다.
