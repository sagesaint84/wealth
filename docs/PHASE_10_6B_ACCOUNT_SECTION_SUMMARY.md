# Phase 10.6B — 증권/은행 계좌 섹션 상단 Summary

## 목적

AccountInfo PDF 가져오기 이후 계좌 수가 늘어나는 상황에서도 자산/계좌 관리 화면에서 전체 계좌 현황을 스크롤 전에 파악할 수 있도록 증권 및 은행 탭 상단에 요약 정보를 제공한다.

## 증권 탭

증권 계좌 목록 위에 다음 4개 요약 카드를 표시한다.

- 총 증권계좌 / 증권사 수
- 총 증권자산 (주식자산 + 기존 계좌 예수금 기준)
- 주식자산 평가금액
- 원화/달러 예수금

`모두` 조회일 때는 가족 구성원별 계좌 수를 함께 표시한다. 가족 구성원 탭을 선택하면 해당 소유자 계좌만 합산한다.

## 은행 탭

기존 은행 금액 요약 카드 앞에 계좌 구성 요약을 추가한다.

- 총 은행 탭 계좌 수 / 금융기관 수
- 자유입출금 계좌 수
- 예·적금/청약 계좌 수
- 대출/마이너스통장 계좌 수

`모두` 조회일 때는 가족 구성원별 계좌 수를 함께 표시한다.

## 데이터 계약

- 증권 요약은 기존 `/api/accounts?group=All&owner=모두` 응답만 사용한다.
- 은행 요약은 기존 `/api/savings` 응답만 사용한다.
- 신규 backend/API/persistence는 추가하지 않는다.
- AccountInfo PDF의 `reported_balance_krw`를 증권 예수금으로 재사용하지 않는다.
- 증권 예수금은 기존 Wealth 계좌의 `cash_krw` / `cash_usd`만 사용한다.
- 가족 필터는 기존 `owner` 계약을 그대로 따른다.

## 안정성

Phase 10.6A2에서 발견된 DOM observer 피드백 루프가 재발하지 않도록 새 요약 모듈의 MutationObserver는 `accountList`와 `savingsSummaryCards`에만 한정한다. 요약 DOM 자체는 감시하지 않으며, 동일 markup은 다시 쓰지 않는다.
